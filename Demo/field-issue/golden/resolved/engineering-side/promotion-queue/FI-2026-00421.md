## Proposed Reusable Finding

Before alignment starts, require position and velocity to remain stable throughout
the configured consecutive sample window. If the guard rejects motion, it should
return `stage_not_stable`.

When fine-alignment error and an X-axis settle timeout occur together, and an
approved sanitized observation confirms motion through the measurement window,
run the approved stage-settling diagnostic before changing vision configuration.
A degraded stage damper is one possible cause, not a default conclusion.

## Scope and Limitations

- Applies only when the approved observation supports persistent X-axis motion.
- The guardrail is supported by the two-file patch and regression evidence in
  mock PR `#1847`; production thresholds remain configuration-owned.
- Does not establish that every alignment error is stage-related.
- Does not authorize physical service outside the approved procedure.
- A component owner must review applicability and wording.
